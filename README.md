# stargazealphatest

stargaze — game project.

A celestial, astronomical, and natal chart exploration web app built with React, Vite, and Tailwind CSS.

## Features
- **play stargaze - coming soon** placeholder landing screen
- **Zodiac Guide**: Complete astronomical knowledge and classical zodiac insights
- **Astral Card Builder**: Full natal chart calculations (Sun, Moon, Rising/Ascendant, Venus, Mars) with local timezone & coordinate support
- **Synastry / Compatibility Explorer**: True multi-planet aspect calculations and synergy percentages
- **Group Cosmos Builder**: Multi-member chemistry and squad synergy matrix
- **Ascendants Explorer**: Accurate spherical trigonometry Ascendant and Whole Sign house calculations
- **Tarot Mirror**: Minimalist daily archetypes and reflections
- **Responsive Glassmorphism**: Clean Apple-style glassmorphism with light mode by default and dark mode toggle

## Scripts
- `npm run dev`: Start local development server
- `npm run build`: Production build with Vite
- `npm run preview`: Preview production build
